# Apex Legends — F1 fan concept

A responsive one-page website built with plain HTML, CSS, and JavaScript. No installation, dependencies, or build step required.

## Open locally

Open `index.html` in a modern browser. All illustrations are original inline SVGs, rendered by JavaScript. Google Fonts is optional; local fallback fonts work offline.

## Deploy with GitHub Pages

1. Extract the ZIP and upload the contents of this folder to a GitHub repository's root.
2. In the repository, go to Settings → Pages.
3. Choose Deploy from a branch, select main and / (root), then Save.
4. GitHub will provide the published URL after deployment.

## Customize before launch

- Replace `hello@example.com` in `index.html` with your real contact address.
- Replace the illustrative opening hours and confirm the venue time zone.
- Edit driver entries in `script.js` and colors and layout in `style.css`.

## Features

- Five historical driver/car pairings with stylized driver and car illustrations.
- Clickable driver cards with detail dialogs, Escape dismissal, and native dialog focus management.
- Responsive navigation, contact email link, concept hours, and reduced-motion support.
- No tracking, backend, forms, or third-party JavaScript.

## Historical references

- [Formula 1 driver guide](https://www.formula1.com/en/drivers)

This is an independent illustrative fan concept, not an official Formula 1 website. Artwork is stylized and does not reproduce exact car geometry, sponsor logos, or photographic likenesses. Team and driver names are used for identification. The schedule and contact address are demo content.
